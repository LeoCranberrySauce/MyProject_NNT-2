# 🍽️ QR Code-Based Computerized Food Ordering System for D Mixologist
An online food ordering system that allows customers to scan a QR code, view the menu, and place orders from their mobile devices. Designed for **D Mixologist*, this system streamlines the ordering process and improves service efficiency.

## 📦 Tech Stack

### Frontend
- React.js

### Backend
- Node.js with Express
- MongoDB (for the Database)

### Other Tools
- QR Code Generator (optional)
- GitHub Projects (for task management)
- Vercel / Render for deployment

## 🚀 Features (Planned)

- [ ] QR Code menu access (optional)
- [x] Menu browsing by category
- [x] Cart & order placement
- [x] Real-time order tracking for kitchen staff
- [x] Admin dashboard for order management
- [x] Testing stripe payments
- [ ] Online payments such as PayMaya or GCash
